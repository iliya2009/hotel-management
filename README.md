# Hotel Management System

A simple hotel management system built with Python.

## Features

- Add passengers with room selection
- Show all passengers
- Remove passengers
- Save/load data in JSON format
- Input validation

## How to Run

1. Make sure Python 3 is installed
2. Run the program:
   python hotel.py

## Technologies

- Python 3
- JSON for data storage
